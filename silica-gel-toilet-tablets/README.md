# Синий краситель для бачка на силикагеле (60 дней)

Силикагель из жидкого стекла и серной кислоты, пищевой краситель E133, ровный цвет ~1 мг/л в смыве.

| № | Вариант | Ровность цвета | Срок |
|---|---|---|---|
| 1 | [Банка с силикагелевым «окном»](variant-1-capsule/README.md) | ~1,1× | 60–80 дней |
| 2 | [Брикет в гильзе, погружён на 1/4](variant-2-partly-submerged/README.md) | 1,6× | ~150 дней |

В каждой папке есть `release_model.js` с расчётом: `node release_model.js`.
